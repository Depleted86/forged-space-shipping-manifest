Forged Space Shipping Manifest

This extension was developed with explicit permission from Coops, the developer of Forged Space.

It makes no network requests of any kind and never transmits anything anywhere. The only data it stores is your own Forged Space game data (inventory, blueprints, builds, and settings), saved locally in your browser and nowhere else.

It is strictly read-only: it only reads what's already on the page you're looking at. It never clicks anything, fills in a form, or takes any action in the game on your behalf. Its own UI on the page - the floating Manifest panel, the Manifest Setup checklist and short notices - is drawn and controlled by the extension itself, separate from the game's own interface, and it never writes to or changes that interface in any way.

The source code is public on GitHub so you (or anyone) can verify all of the above for yourself, rather than just taking our word for it.

This is an independently maintained fan tool, not an official part of the game. Forged Space itself is still being actively rebuilt, and its pages can be restyled or rewritten with no notice - when that happens, this extension can break in ways that look wrong or show bad numbers. If something stops working after a Forged Space update, that means this extension needs fixing - not that your game or your save is broken.

Open Forged Space and a Manifest Setup window on the game page walks you through the few screens to visit so the planner knows your storage, skills and blueprints.
